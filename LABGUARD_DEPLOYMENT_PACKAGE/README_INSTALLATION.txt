================================================================================
- LABGUARD-Setup.exe       : గ్రాఫికల్ విండోస్ సెటప్ విజార్డ్ (GUI-Based Setup Wizard - RECOMMENDED).
- Install_LABGUARD.bat     : సింగిల్-క్లిక్ సైలెంట్/కన్సోల్ ఇన్స్టాలర్ (One-Click Script Installer).
- LABGUARD.exe             : లేటెస్ట్ నేటివ్ 64-బిట్ ప్రొడక్షన్ బైనరీ (Native Application Binary).
- WebView2Loader.dll       : మైక్రోసాఫ్ట్ వెబ్‌వ్యూ2 రన్‌టైమ్ లైబ్రరీ (Prevents missing DLL crashes).
- Set_Server_IP.bat        : సెంట్రల్ ల్యాబ్ సర్వర్ IP కాన్ఫిగర్ టూల్ (Configure Server IP across LAN).
- logo.ico                 : అఫీషియల్ ఇన్‌స్టిట్యూషనల్ అప్లికేషన్ ఐకాన్ (Desktop / Start Menu Icon).
- README_INSTALLATION.txt  : పూర్తి యూజర్ గైడ్ మరియు డాక్యుమెంటేషన్ (Instructions Guide).

2. HOW TO INSTALL ON ANOTHER SYSTEM (వేరే సిస్టమ్‌లో ఎలా ఇన్స్టాల్ చేయాలి):
================================================================================

పద్ధతి 1: GUI సెటప్ విజార్డ్ (అత్యంత సులభమైన గ్రాఫికల్ పద్ధతి - RECOMMENDED)
-------------------------------------------------------------------------
1. "LABGUARD-Setup.exe" ఫైల్ పై డబుల్-క్లిక్ చేయండి.
2. స్క్రీన్ పై అందమైన విండోస్ గ్రాఫికల్ ఇన్‌స్టాలేషన్ విజార్డ్ (GUI Wizard) ఓపెన్ అవుతుంది:
   - "Next" బటన్ నొక్కండి.
   - ఇన్‌స్టాలేషన్ లొకేషన్ ఎంచుకోండి.
   - డెస్క్‌టాప్ ఐకాన్, ఆటో-స్టార్ట్ ఆప్షన్లు టిక్ చేసుకోండి.
   - Central Server IP ఎంటర్ చేయండి (ల్యాబ్ సర్వర్ IP లేదా డీఫాల్ట్ localhost).
   - "Install" బటన్ నొక్కండి (అనిమేటెడ్ ప్రోగ్రెస్ బార్‌తో ఫైల్స్ కాపీ అవుతాయి).
   - "Finish" నొక్కిన వెంటనే LABGUARD అప్లికేషన్ లాంచ్ అవుతుంది!

పద్ధతి 2: 1-క్లిక్ కన్సోల్ బ్యాచ్ ఇన్స్టాలర్ (Batch Script Method)
----------------------------------------------------------------
1. "Install_LABGUARD.bat" పై రైట్-క్లిక్ చేసి "Run as administrator" ఎంచుకోండి.
2. స్క్రిప్ట్ స్వయంచాలకంగా ఫోల్డర్లు, పర్మిషన్స్, షార్ట్‌కట్స్ మరియు అన్‌ఇన్‌స్టాలర్ రిజిస్టర్ చేస్తుంది.

3. KIOSK ANTI-TAMPER & DYNAMIC STAFF EXIT (యాప్ క్లోజ్ కాకుండా రక్షణ):
================================================================================
- స్టూడెంట్స్ లాగిన్ కాకముందు లేదా సెషన్‌లో ఉన్నప్పుడు యాప్‌ను క్లోజ్ చేయలేరు (Alt+F4 & Close buttons blocked).
- ల్యాబ్ అసిస్టెంట్, ఫ్యాకల్టీ లేదా అడ్మిన్ యాప్‌ను క్లోజ్ చేయాలనుకుంటే "Staff Exit" బటన్ నొక్కి తమ Login Password ఎంటర్ చేయాలి.
- ఏ Faculty / Assistant / Admin యూజర్ పాస్‌వర్డ్ అయినా Staff Exit Key గా పనిచేస్తుంది (Students పాస్‌వర్డ్‌లు నిరోధించబడతాయి).

4. CONNECTING WORKSTATIONS TO CENTRAL SERVER (నెట్‌వర్క్ సర్వర్ కనెక్టివిటీ):
================================================================================
లాబ్‌లో ఒక కంప్యూటర్ Server గా ఉండి, మిగతావి Workstations గా ఉంటే:
1. సర్వర్ కంప్యూటర్ యొక్క Local IP ని తెలుసుకోండి (ఉదా: 192.168.1.100).
2. వర్క్‌స్టేషన్ పీసీలో:
   - "Set_Server_IP.bat" ఓపెన్ చేసి, సర్వర్ IP ఎంటర్ చేయండి.
   - లేదా LABGUARD యాప్ లాగిన్ స్క్రీన్‌పై "Server IP" బటన్ నొక్కి IP మార్చుకోవచ్చు.
3. టెస్ట్ కనెక్షన్ గ్రీన్ రంగులో కనిపిస్తే వెంటనే వర్క్‌స్టేషన్ సర్వర్‌కు కనెక్ట్ అవుతుంది!
4. ఒకవేళ నెట్‌వర్క్ కట్ అయినా, యాప్ క్రాష్ అవ్వదు - ఆటోమేటిక్‌గా "Offline Vault Mode" లోకి మారి 
   లోకల్ SQLite డేటాబేస్ వాడుకుంటుంది.

5. WHY IT WILL NEVER CRASH (క్రాష్ అవ్వకుండా తీసుకున్న జాగ్రత్తలు):
================================================================================
- Automatic Vault Provisioning: C:\ProgramData\LABGUARD కి Full Control పర్మిషన్స్ ఇవ్వబడతాయి.
  సాధారణ స్టూడెంట్ Windows యూజర్ అకౌంట్ అయినా డేటాబేస్ పర్మిషన్ ఎర్రర్ రాదు.
- Statically Linked SQLite: rusqlite బండిల్ చేయబడింది కాబట్టి బాహ్య డ్రైవర్ల అవసరం లేదు.
- Bundled WebView2Loader.dll: మిస్సింగ్ DLL ఎర్రర్స్ రాకుండా బండిల్ చేశాము.
- Graceful Offline Fallback: నెట్‌వర్క్ డిస్కనెక్ట్ అయినా UI క్రాష్ అవ్వకుండా ఆఫ్‌లైన్ లోడ్ అవుతుంది.
- Safe Shutdown Guards: స్టూడెంట్ మాత్రమే పీసీ ఆఫ్ చేయగలరు; అడ్మిన్/ఫ్యాకల్టీ లాగౌట్ అయినప్పుడు 
  సిస్టమ్ షట్‌డౌన్ కాకుండా పూర్తి ప్రొటెక్షన్ ఉంటుంది.
